**Mlnchly** is a **multi-tool** created using the **Python** programming language; it's full functionality is described below.
---

**Installation**:

```bash

git clone https://github.com/osoreruu/Mlnchly.git

cd Mlnchly

pip install -r requirements.txt

```

---

**Usage**:

```bash

python main.py

```

Then select **desired** tool by numbers

**Advantages of my tool**: modularity, lightweight design, and speed.

---

**Functions**:

**Hashing**: **MD5**, **SHA1**, **SHA256**, **SHA3_384**, **SHA3_512**, **Blake2b**
**Symmetric Encrypt**: **AES256GCM**, **ChaCha20Poly1305**
**Asymmetric** Encrypt: **RSA2048**, **ECC256**
**Decrypting** of **Symmetric and Asymmetric Encryption's**
**Generating password** of every length, used safe **import secrets**.
**Brute-Forcing** password with **RockYou.txt** and dump method.
**Generating UserAgents** with **fake_useragent** library.
**Parser of robots.txt and sitemap.xml** with requests for parsing file used for other parsers.
**Port Scanner** using for scan port and determine whether it is open or not.
**HWID Generatorr** generating your **HWID** by **Board Serial**, **Product Serial** and **Product UUID**
